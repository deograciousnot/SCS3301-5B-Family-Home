# SCS3301 Computer Graphics – Project 5B: Family Home

An interactive 3D family home built in base MATLAB, with hinged doors, a fridge, a TV, a cooker, a day/night cycle and a night-mode challenge.

- **Run it:** open the `code/` folder in MATLAB and run `run_project`. The controls are in [`code/README.txt`](code/README.txt).
- **New to the project? Start here:** [`GROUP_PLAN.md`](GROUP_PLAN.md) (setup, how the code works, roles, Git). Please read it first.
- **Proposal draft:** `docs/M1_proposal/`
